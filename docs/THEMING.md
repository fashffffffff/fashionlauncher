# Темы оформления

Внешний вид лаунчера задаётся темой — маленьким текстовым файлом `.json`.
Его можно скопировать, поменять пару цветов и сразу увидеть результат.
Программировать для этого не нужно.

## Самый простой способ — редактор в лаунчере

Откройте **Настройки → Оформление**. Там можно выбрать тему, поменять цвета,
скругления и фон. Встроенные темы не портятся: при первом изменении лаунчер
сам делает вашу копию («Моя Deepslate» и т. п.) и дальше правит уже её.

## Где лежат темы

Ваши темы хранятся в папке `ui-themes` внутри папки данных лаунчера.
Проще всего открыть её кнопкой **«Открыть папку тем»** в разделе «Оформление».

Обычно это:

| Система | Путь |
|---|---|
| Windows | `%APPDATA%\PrismLauncher\ui-themes` |
| macOS | `~/Library/Application Support/PrismLauncher/ui-themes` |
| Linux | `~/.local/share/PrismLauncher/ui-themes` |

В портативной версии папка `ui-themes` лежит рядом с самим лаунчером.

## Как сделать свою тему

1. В разделе «Оформление» выберите понравившуюся тему и нажмите
   «Дублировать» — в папке появится её копия. Или просто создайте в папке
   новый файл, например `my-theme.json`.
2. Откройте файл любым текстовым редактором (Блокнот тоже подойдёт).
3. Поменяйте что хотите и сохраните.

**Изменения применяются сразу после сохранения** — перезапускать лаунчер
не нужно. Если в файле ошибка (например, забыли запятую), лаунчер покажет
сообщение и временно включит стандартную тему; исправьте файл и сохраните
ещё раз.

## Минимальный пример

В теме не нужно перечислять всё. Укажите только то, что хотите поменять —
остальное возьмётся из стандартных настроек:

```json
{ "name": "Изумруд",
  "colors": { "accent": "#17C964", "onAccent": "#04210F" } }
```

Это вся тема: название и цвет акцента (кнопки, выделение, активный слот).

## Что означает каждый параметр

Цвета записываются в формате `#RRGGBB`, например `#F5A524`. Подобрать цвет
можно в любом онлайн-«color picker».

### Общее

| Ключ | Что это |
|---|---|
| `name` | Название темы в списке |
| `author` | Автор (необязательно) |
| `dark` | `true` — тёмная тема, `false` — светлая |

### `colors` — цвета

| Ключ | Что это |
|---|---|
| `bg` | Основной фон окна |
| `surface` | Фон панелей и карточек |
| `surfaceHi` | Панель при наведении, выделенные элементы |
| `line` | Тонкие рамки и разделители |
| `text` | Основной текст |
| `textMuted` | Второстепенный текст: подписи, подсказки |
| `accent` | Главный цвет темы: кнопки, активный слот, ползунки |
| `onAccent` | Текст и значки поверх акцентного цвета |
| `danger` | Ошибки и опасные действия (удаление) |
| `success` | Успех: «готово», «запущено» |
| `scrim` | Цвет затемнения поверх фоновой картинки |

### `shape` — форма

| Ключ | Что это |
|---|---|
| `radius` | Скругление углов панелей и кнопок (в пикселях, `0` — острые углы) |
| `slotRadius` | Скругление слотов хотбара |
| `slotSize` | Размер слота хотбара в пикселях |

### `type` — шрифты

| Ключ | Что это |
|---|---|
| `display` | Шрифт крупных заголовков (по умолчанию Unbounded) |
| `ui` | Шрифт интерфейса (по умолчанию Golos Text) |
| `scale` | Масштаб текста: `1.0` — обычный, `1.2` — на 20 % крупнее |

Шрифт должен быть установлен в системе, иначе будет использован стандартный.

### `background` — фон

| Ключ | Что это |
|---|---|
| `mode` | Что показывать на фоне (см. ниже) |
| `image` | Имя файла картинки для режима `image` |
| `blur` | Размытие фона: `0` — чёткий, `32` — сильно размыт |
| `dim` | Затемнение фона от `0` (нет) до `1` (полностью цветом `scrim`) |

### `motion` — анимации

| Ключ | Что это |
|---|---|
| `enabled` | `false` — выключить анимации |
| `speed` | Скорость: `1.0` — обычная, `0.5` — вдвое медленнее, `2.0` — вдвое быстрее |

## Фон

У `background.mode` четыре варианта:

- `screenshot` — последний скриншот выбранной сборки. Фон меняется, когда
  вы выбираете другую сборку в хотбаре. Если скриншотов нет, будет узор.
- `image` — ваша картинка. Положите файл (`.png` или `.jpg`) **в ту же папку
  `ui-themes`**, где лежит тема, и укажите его имя: `"image": "forest.jpg"`.
  Полный путь писать не нужно. Кнопка «Выбрать картинку» в редакторе делает
  всё это сама.
- `pattern` — спокойный узор в цветах темы.
- `solid` — просто цвет `bg`.

Если картинка слишком яркая и текст плохо читается, увеличьте `dim`
или `blur`.

Пример:

```json
{ "name": "Мой лес",
  "background": { "mode": "image", "image": "forest.jpg", "blur": 12, "dim": 0.4 } }
```

## Как поделиться темой

Отправьте другу файл темы `.json`. Если тема использует картинку — отправьте
и картинку тоже. Другу достаточно положить оба файла в свою папку `ui-themes`:
тема сразу появится в списке.
